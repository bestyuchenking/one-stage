## Image behavior

- Desktop: move the mouse over a project image to automatically advance through its available images.
- Desktop: arrow controls appear on hover for manual navigation.
- Mobile/tablet: swipe left/right on the image to navigate.
- Missing image files are ignored automatically, so a project can contain 1–4 images.
- Until the new named images are uploaded, the previous single project image is used as a fallback.

Recommended: JPG, landscape orientation, preferably around 16:10 or 3:2, with a consistent export width across the portfolio.
