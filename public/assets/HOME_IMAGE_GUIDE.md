# OneStage image upload guide

Please upload the following JPG images into `public/assets/`:

- `home-entertainment.jpg` — homepage panel 02 / OneStage Entertainment
- `home-collection.jpg` — homepage panel 03 / OneStage Collection
- `duku-2401-cover.jpg` — Collection featured publication / 读库2401 cover

Homepage panel 01 is already configured to use `project03_2.jpg` (Greentown Majestic Mansion / 锦玉园). The build workflow converts project images, the two home images, and the 读库 cover to WebP automatically.

Expected generated files:
- `project03_2.webp`
- `home-entertainment.webp`
- `home-collection.webp`
- `duku-2401-cover.webp`

Keep the original JPGs in the repository; they are the source files and are not replaced.
